# SirenX Version History

SirenX was released before this GitHub repository was created. This file
preserves the published update history for earlier releases. GitHub Releases
are used for release notes from the first release tracked in this repository
forward.

SirenX is distributed free through the Apple App Store. GitHub Releases do not
include application installers.

## Earlier Releases

### 1.5 — 2026-06-23

- Added EQ and headphone profile support.
- Added playback queue.
- Added online lyric matching.

### 1.4 — 2026-05-27

- Refined player interactions for a simpler, smoother experience.
- Improved music import parsing.

### 1.3 — 2026-05-10

- Added import from supported cloud drives.
- Added SMB network-storage import.

### 1.2 — 2026-04-25

- Added Search and a new Songs view.
- Improved playback for a smoother listening experience.

### 1.1 — 2026-04-10

- Added Voice Command for quick album access.
- Improved playback stability.
